# Bildquellen und Alt-Texte

Stand: 26. Juli 2026

## Grundsätze

- Vorhandene eigene Projekt- und Designbilder werden bevorzugt.
- Ergänzende Stockfotos werden lokal als komprimierte WebP-Dateien ausgeliefert. Es gibt keine Hotlinks.
- Informative Bilder besitzen einen konkreten deutschen Alt-Text. Rein dekorative Icons besitzen bewusst `alt=""`, damit Screenreader sie überspringen.
- Ein Leitmotiv wird nicht für mehrere Kernseiten wiederverwendet.
- Die technische Zuordnung liegt zentral in `data/marketingImages.js`.
